# Meerkat Workshop - Plan 3 (分散型意思決定を伝える強化版)

## 1. 目的
- 現在のデモを「動いている」状態から、「分散型意思決定の仕組みが一目で伝わる」状態へ引き上げる。
- 重点は UI の派手さではなく、意思決定の成立プロセスの可視化。

## 2. Plan 1 / Plan 2 からの追加ポイント
- 意思決定カードにエージェント寄与（誰が support / attack したか）を追加する。
- イベント押下時の固定加算だけでなく、tick ごとの局所ルール評価で値が積み上がるようにする。
- 「中央管理者なし」をデモ中に説明しやすい表示（ログと内訳）を用意する。

## 3. 追加 Build Tasks

### P0（必須）
1. `Task 12`: エージェント寄与データモデル追加
   - 内容: 候補ごとに `byAgentSupport` / `byAgentAttack` を保持する。
   - 完了条件: 3候補すべてで、エージェント別の寄与値を参照できる。
   - 目安: 20分

2. `Task 13`: 意思決定カードに寄与内訳を表示
   - 内容: 各カードに「Agent名 + support/attack」を小さく表示する。
   - 完了条件: イベント後に内訳が更新され、誰の影響か追える。
   - 目安: 25分

3. `Task 14`: tick ベースの局所ルール判定を実装
   - 内容: 各エージェントが担当エリア状態だけを見て support/attack を毎 tick 追加する。
   - 完了条件: イベントを1回押した後も、局所状態に応じて値が継続更新される。
   - 目安: 40分

4. `Task 15`: ルール発火ログを追加
   - 内容: 「QA -> Fix Tunnel support +1」のような短いログを出す。
   - 完了条件: 直近5件で、候補確定前の寄与過程が追える。
   - 目安: 20分

5. `Task 16`: デモ専用シナリオボタンを追加
   - 内容: `electricity price -> rush order -> defect` を自動発火する。
   - 完了条件: 1クリックで再現性高く分散意思決定の流れを見せられる。
   - 目安: 25分

### P1（余力があれば）
1. `Task 17`: 反対意見（attack）の視認性を強化
   - 内容: support と attack の色分けと差分（support-attack）表示を追加する。
   - 完了条件: 「支持が多いから確定」だけでなく「反対を上回ったから確定」が説明できる。
   - 目安: 20分

2. `Task 18`: 確定条件のチューニング
   - 内容: 閾値・蒸発率を調整し、30-60秒で1回以上確定する挙動にする。
   - 完了条件: 本番デモで詰まりにくい。
   - 目安: 15分

## 4. デモ運用タスク（発表向け）
1. `Pitch 04`: 分散型の説明を3文で固定
   - 「中央管理者はいません」
   - 「各エージェントは担当領域だけを見て signal を出します」
   - 「合算 signal が閾値を超えると決定が確定します」

2. `Pitch 05`: 画面上の見る順番を固定
   - 手順: イベントボタン -> エージェント内訳 -> CONFIRMED -> ログ

3. `Pitch 06`: 失敗時バックアップ導線
   - 内容: デモ開始前に寄与値を少し溜めた `warmup` 状態を1つ用意する。

## 5. Definition of Done（Plan 3）
- 観客が「誰が何を根拠に押した結果、何が確定したか」を画面だけで追える。
- 1分以内に少なくとも1回 `Decision Confirmed` を再現できる。
- 「中央命令でなく、場の蓄積で決まる」ことをログと内訳で説明できる。
